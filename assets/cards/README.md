# 偉特塔羅牌圖來源

78 張牌面採自 Rider–Waite–Smith 塔羅的 1910 年 Pamela-A 版實體掃描。牌面由 Pamela Colman Smith 繪製，由 Arthur Edward Waite 指導，William Rider & Son 出版。Wikimedia Commons 將這些檔案標為公有領域。本站縮小圖片並轉為 WebP，保留每張牌原有的圖面、比例與色彩。

- [Wikimedia Commons 的 Rider–Waite 塔羅分類](https://commons.wikimedia.org/wiki/Category:Rider-Waite_tarot_deck)
- [公有領域標記](https://creativecommons.org/publicdomain/mark/1.0/)
